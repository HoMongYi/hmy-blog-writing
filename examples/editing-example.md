# 일부 문단 편집 예시

입력과 편집 결과는 모두 합성 데이터다. 실제 사용자 답변이나 블로그 원고에서 가져오지 않았다.

## 입력

> 가상 테스트 기록에서 파일 수는 12개였다. 파일명 변경은 3분이 소요되었으며, 변경이 완료된 이후 목록을 다시 확인하는 작업을 진행했다. 이름이 같은 파일은 존재하지 않는 것으로 확인되었다. 원래 이름을 적어 둔 메모는 남겨 뒀다.

요청: 의미·수치·행동을 보존하고 어색한 표현만 다듬는다. 자연스러운 마지막 문장은 유지한다.

## 편집 결과

가상 테스트 기록의 파일은 12개였다. 이름을 바꾸는 데 3분이 걸렸고, 바꾼 뒤 목록을 다시 확인했다. 같은 이름의 파일은 없었다. 원래 이름을 적어 둔 메모는 남겨 뒀다.

## 변경 이유

‘작업을 진행했다’, ‘존재하지 않는 것으로 확인되었다’를 간결하게 바꿨다. 파일 수·소요 시간·재확인 행동과 마지막 문장을 유지했다. “늘 메모를 남긴다” 같은 새로운 습관이나 “매번 3분이면 끝난다” 같은 일반화는 추가하지 않았다.

실제 글을 편집할 때는 이 합성 기록을 작성자의 경험 근거로 사용하지 않는다.
